# 🤖 AI Chatbot using Flask & Ollama

An AI-powered chatbot built using **Python, Flask, HTML, CSS, JavaScript, and Ollama (Llama 3.2:1B)**. The chatbot runs locally using a Large Language Model (LLM) and provides an interactive chat experience through a clean web interface.

---

## 🚀 Features

- 💬 Interactive AI chatbot
- 🤖 Local AI responses using Ollama (Llama 3.2:1B)
- ⌨️ Send messages with the Enter key
- 🧠 "Thinking..." loading indicator
- 🗑️ Clear Chat button
- 🕒 Message timestamps
- ✨ Smooth message animations
- 📱 Responsive user interface
- ⚠️ Error handling for failed requests

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/AI-Chatbot-Using-Flask-and-Ollama.git
```

### 2. Go to the project folder

```bash
cd AI-Chatbot-Using-Flask-and-Ollama
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Make sure Ollama is installed and the model is available

```bash
ollama run llama3.2:1b
```

### 5. Start the Flask application

```bash
python app.py
```

### 6. Open your browser

```
http://127.0.0.1:5000
```
